# 📊 Power BI Data Analytics Assignments & Projects

This repository contains various data analytics assignments and dashboards built using *Microsoft Power BI*, utilizing DAX queries, calculated columns, measures, and interactive visualizations.

---

## 📁 Datasets & Exercises Covered

### 1. Amazing Mart Dataset
* *Datasets Used:* List of Orders, Order Breakdown
* *Tasks Performed:*
  * Loaded and established relationships (Order ID) between multiple tables.
  * Created a *Clustered Column Chart* to display countries with the highest order placements.
  * Configured data sorting and formatting for clear visual insights.

### 2. Customer Data
* *Dataset Used:* Customer Data.xlsx
* *Tasks Performed:*
  * Created a *Line Chart* showing the count of orders received per date.
  * Added a *Calculated Column* using DAX (Quantity * Price Per Unit) to replicate total pricing.
  * Implemented various *DAX Measures*:
    * Total Sum (SUM)
    * Total Rows (COUNTROWS)
    * Valid Records Count (COUNT)
    * Missing Values Count (COUNTBLANK)
    * Minimum & Maximum Values (MIN, MAX)

### 3. Employee Layoffs Dataset
* *Dataset Used:* Employee Layoffs.xlsx
* *Tasks Performed:*
  * Built a *Pie/Donut Chart* to analyze locations with the highest number of layoffs (Total Laid Off).
  * Optimized visualizations for large categorical distributions using Top N filters and bar chart alternatives.


## 🛠️ Tools & Technologies Used
* *Microsoft Power BI Desktop*
* *DAX (Data Analysis Expressions)*
* *Power Query Editor*
* *Git & GitHub* for version control and submission
